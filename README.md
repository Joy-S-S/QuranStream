# إذاعة القرآن الكريم — البث المباشر والتسجيل الصوتي

منصة ويب عصرية للاستماع إلى إذاعة القرآن الكريم والبث المباشر لكبار القراء مع مواقيت الصلاة وتسجيل التلاوات الخاشعة وقصّها محلياً بالكامل.

## المميزات الرئيسية

- **بث مباشر مستقر وعالي الجودة**: يدعم إذاعة القرآن الكريم من القاهرة، مكة المكرمة، كبار القراء (المنشاوي، عبد الباسط، الحصري، العفاسي) وسلسلة خواطر الشيخ محمد متولي الشعراوي.
- **تسجيل صوتي محلي 100% (بدون خادم أو نطاق خارجي)**:
  - تسجيل البث الإذاعي مباشرة من داخل المتصفح عبر Web Audio API و `MediaRecorder`.
  - إمكانية تسجيل الصوت الشخصي عبر الميكروفون.
  - إصلاح ترويسة مدة ملفات WebM/M4A تلقائياً لضمان التقديم والتأخير الدقيق في مشغلات الوسائط.
- **محرر وقاطع صوتي مدمج**: قص المقاطع المسجلة بسهولة وتحديد بدايتها ونهايتها عبر منزلق دقيق وتنزيلها بصيغة صوتية قياسية.
- **مكتبة التسجيلات المحفوظة**: حفظ التسجيلات محلياً داخل المتصفح عبر `IndexedDB` دون إرسال أي بيانات لخوادم طرف ثالث.
- **مواقيت الصلاة الدقيقة والعد التنازلي**: تدعم مدن جمهورية مصر العربية والمملكة العربية السعودية والعواصم الإسلامية مع خيار تحديد الموقع الجغرافي التلقائي (GPS) والتخزين المؤقت.
- **آية اليوم المباركة**: عرض آية قرآنية يومية بخط «الأميري» العريق مع اسم السورة وزر النسخ بنقرة واحدة.
- **مؤقت الإيقاف التلقائي (Sleep Timer)**: ضبط إيقاف البث تلقائياً بعد 15، 30، 45، 60، أو 90 دقيقة.
- **تصميم إسلامي هادئ واحترافي**:
  - لوحة ألوان منتقاة بعناية (Emerald / Slate / Warm Sand).
  - خالٍ تماماً من الرموز التعبيرية العشوائية وألوان قوس قزح والعبارات التسويقية المصطنعة.
  - خطوط عربية أصيلة: `Readex Pro` لواجهة المستخدم و `Amiri` للخط القرآني.
  - دعم كامل لاتجاه القراءة من اليمين إلى اليسار (`dir="rtl"`).
  - متجاوب كلياً على كافة الشاشات ونسب التكبير (100%، 125% وأجهزة الجوال والأجهزة اللوحية).
- **جاهز للنشر المجاني على GitHub Pages**: تصدير ثابت كلياً (`output: 'export'`) بدون أي متطلبات بايثون أو استضافة سحابية مدفوعة.

## متطلبات التشغيل

- [Node.js](https://nodejs.org/) (الإصدار 18 أو أحدث)
- مدير الحزم `npm`

---

## التشغيل المحلي

```bash
# تثبيت الحزم
npm install

# تشغيل خادم التطوير
npm run dev
```

افتح المتصفح على: `http://localhost:3000`

---

## التصدير للإنتاج (GitHub Pages)

```bash
# إنشاء النسخة الثابتة
npm run build
```

سيتم إنشاء مجلد `out` الذي يحتوي على جميع ملفات الموقع الجاهزة للنشر المباشر.

### خطوات النشر على GitHub Pages:
1. ارفع المشروع إلى مستودع GitHub.
2. اذهب إلى **Settings** > **Pages** في مستودعك.
3. تحت **Build and deployment**، اختر:
   - **Source**: `Deploy from a branch`
   - **Branch**: اختر الفرع الرئيسي وحدد المجلد `/out` (أو استخدم GitHub Actions الجاهز لمشاريع Next.js الثابتة).
